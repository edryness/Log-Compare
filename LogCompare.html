Log Compare

Load two text files side by side and see every line that differs. Built for comparing a working and a non-working customer log set.

Colors

ChangedThe line exists on both sides but differs. The differing words are marked  red  on the left and  green  on the right.
Only in leftThe line is in the left file only. The right side shows a hatched gap.
Only in rightThe line is in the right file only. The left side shows a hatched gap.
dimmed textIgnored by the current Ignore options (for example timestamps).

Keyboard

F8 Alt+↓ NNext difference
Shift+F8 Alt+↑ PPrevious difference
↑ ↓Move the selected line
Ctrl+FFind text in both files; Enter / Shift+Enter for next / previous match

Mode

  • Smart align (default) lines up matching lines, so one extra line in a file doesn't make everything after it look different. Works like Notepad++ Compare or WinMerge.
  • Line-by-line compares line N of the left file with line N of the right file, strictly.

Ignore

  • Timestamps: 2026-09-11T12:24:49.032, 2026-05-20T13:52:35Z, 5/21/2026 04:24:56 AM, 21.05.2026, 12:24:49 and similar.
  • PIDs/TIDs: pid:37956, tid:41512, [Pid:27528], PPID:6516:134336030897377560, Process ID: 1234.
  • GUIDs, Case, Whitespace, or any custom regex (for example 0x[0-9a-f]+ or ScanRequest #\d+).

Files

UTF-8, UTF-16 (with or without a byte-order mark, such as MPOperationalEvents.txt and MPLog files) and Windows-1252 are detected automatically. Save report writes every difference with its line numbers to a .txt file you can attach to a case. Everything runs locally in this page.
